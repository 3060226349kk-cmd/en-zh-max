# 长任务交接：分会话做，省 token

会话越长，每一轮都要把整个上下文重读一遍。实测：一个整本书项目全程只开一个会话，上下文涨到 96 万 token，平均每章耗 1400 万；新会话起步只要 3 到 5 万。所以大档（整本书、长篇系列）按单元收尾、交接，换新会话接着译。一个会话译不完的长文（约 2 万词、日文约 4 万字以上）也按大档建项目目录，照此办理。

本文件三个翻译技能共用（es-zh-max 为正本，en-zh-max、jp-zh-max 的 `references/handoff.md` 是副本），内容保持一致。`$SKILL_DIR` 指本技能所在目录。

## 1. 什么时候交接
**每做完一个单元**，量一次：
```bash
python3 "$SKILL_DIR/scripts/handoff.py" meter --done <本会话已做完的单元数>
```
- **单元**：一章。超过约 8000 词（日文约 1.5 万字）的章拆成几段，每段算一个单元，在 `translation-plan.md` 里分行勾选。
- **做完**：定稿、机检、合订或导出（如有）、勾选进度、补完术语表。半截的单元不算。
- 输出「→ 交接」就交接，「→ 继续」就做下一个单元。
  - Claude Code 里，脚本读本会话的实际上下文，达到 15 万 token 判交接。
  - 读不到用量的 agent，按本会话做完 2 个单元判交接。
  - 阈值用 `--limit` 临时改；要长期改，改脚本里的 `LIMIT`，再把三份脚本同步。

**不等单元做完，立即交接**：
- 收到额度将尽、上下文将满、即将压缩之类的系统提示。
- 用户说「暂停」「交接」「先到这里」。

这时在「下一步」里写清半截的单元做到了哪一步、草稿在哪个文件。

## 2. 怎么交接
1. **先落盘**。HANDOFF 只写文件里还没有的东西：
   - 新定的译名、语域标记、体例，写进 `TERMS_GLOSSARY.md`。
   - 进度在 `translation-plan.md` 里勾选；用户的长期指令和项目工具的用法，写进 `translation-plan.md` 开头。
   - 项目专用脚本放在 `项目目录/tools/`。会话临时目录（scratchpad、/tmp）到了新会话就找不到了。
2. **写交接**，覆盖旧的 HANDOFF.md：
   ```bash
   python3 "$SKILL_DIR/scripts/handoff.py" write "<项目目录>" --next "<下一步>" --notes - <<'EOF'
   - 本会话议定、还没写进文件的事项
   - 半截的工作、踩过的坑
   EOF
   ```
   脚本写好续接顺序和进度，打印续接命令，并复制到剪贴板。它提醒「提到了临时目录」时，先把脚本移进 `tools/`，再重写一次。
3. **停下**，不开下一个单元。收尾只告诉用户三件事：本会话做完了什么；下一步是什么；续接命令（已在剪贴板里，开新窗口或 `/clear` 后粘贴）。
4. 交接之后，这个会话再收到「继续」（包括额度恢复后的自动续跑），只重复一遍续接命令，不在旧会话里接着译。

## 3. 怎么续接
用户说「续译 <目录>」，或说「继续」而项目目录里有 HANDOFF.md 时：
1. 依次读 HANDOFF.md、`translation-plan.md`、`TERMS_GLOSSARY.md`，再读本技能中档要读的参考文件。进度以 `translation-plan.md` 的勾选为准；它比 HANDOFF 新时，从勾选处接着做。
2. 已定稿的章节、合订本、整本原文都不回读；要查旧译法，就 grep 术语表或上一章。
3. 从「下一步」接着做。本会话的单元数从 0 算起。

## 4. 自动接力
只在用户说「自动接力」时用，限能派子代理的 agent（如 Claude Code）；其他 agent 照第 2 节交接。主会话只调度，自己不译：
1. 从 `translation-plan.md` 找出下一个没勾选的单元，派一个新的子代理，一次只派一个。提示词：
   > 用 <技能名> 技能续译 <项目目录>，只做「<单元>」这一个单元。先读 HANDOFF.md、translation-plan.md、TERMS_GLOSSARY.md，按大档流程做完：定稿、机检、合订、勾选、补术语表。做完跑 `handoff.py write --no-copy`，「下一步」写下一个单元。最后只回一行：单元名、结果、要用户定夺的问题。不要开始下一个单元。
2. 子代理回来后，grep `translation-plan.md` 确认这个单元已勾选，给用户一行进度，再派下一个。
3. 子代理出错或中断：读 HANDOFF.md 看停在哪里，同一单元重派一次；再失败就停下，报告用户。
4. 子代理不跑 meter。主会话每派完一个单元跑一次，到了阈值也照第 2 节交接；`write` 加 `--relay`，续接命令会带上「自动接力」。

## 5. 单元内省 token
- 刚写完的译文还在上下文里，修订就直接定点改，不要为了修订再整篇读一遍。
- 命令输出只看摘要：长输出接 `| tail -20`，机检只看汇总和要判断的行。
- 参考文件每个会话只读一次。
